# Changelog

## 1.0.0 — 2026-08-17

- Rilis awal platform WangStore: katalog, Server Builder, pemesanan, autentikasi, portal pelanggan, CMS admin, kupon, tiket, status, VPS, dan lifecycle layanan.
- Menambahkan adapter Supabase untuk production dan datastore JSON atomik untuk pengembangan lokal.
- Menambahkan dokumentasi keamanan, API, arsitektur, deployment Vercel, serta skema PostgreSQL dengan RLS.
- Menambahkan konfirmasi renewal manual yang transaksional dan idempoten, riwayat renewal customer/admin, pembatasan satu renewal pending, serta pengujian transisi katalog Medium dan lifecycle renewal.
