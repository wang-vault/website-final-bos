# Berkontribusi

1. Gunakan Node.js 20 atau lebih baru dan buat branch dari `main`.
2. Salin `.env.example` menjadi `.env.local`; jangan commit secret.
3. Jalankan `npm install`, lalu `npm run check` sebelum pull request.
4. Sertakan pengujian untuk perubahan pricing, otorisasi, atau lifecycle.
5. Seluruh teks antarmuka harus profesional dalam Bahasa Indonesia. Jangan menambahkan klaim bisnis yang tidak dapat diverifikasi.
6. Perubahan skema production harus dimasukkan ke `database/schema.sql` dan didokumentasikan.

Laporkan kerentanan secara privat melalui kanal kontak pemilik repository, bukan issue publik.
